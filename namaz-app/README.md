# Namaz App

Android-приложение для расписания намазов.

## Цель

Создать бесплатное приложение с расписанием намазов по городам.

## План

- [ ] Выбор города
- [ ] Расписание на день
- [ ] Расписание на месяц
- [ ] Исламская дата
- [ ] Текущий намаз
- [ ] Следующий намаз
- [ ] Пост
- [ ] Настройка внешнего вида
- [ ] Тестирование
- [ ] Сборка APK
